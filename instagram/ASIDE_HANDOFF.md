# Aside — Minimal Two-Account Execution SOP

Read first: `instagram/README.md`, the IG-DUO-01 Notion control hub, and Jira umbrella + channel tasks.

## Permission matrix
**PRE-AUTHORIZED:** read-only audit; publicly sourced references; create copyright-safe original artwork/scripts; create local/exportable posts; edit approved raw clips; factual/audio/privacy QA; Git asset preparation in isolated branch/PR; Notion/Jira evidence updates; posts as drafts/packages.
**CONDITIONAL after exact account verification + explicit owner approval:** apply profile avatar, display name, bio, category or other harmless fields; use official platform schedule/post integration for a specific approved post.
**OWNER-ONLY by default:** signup/login, credentials/MFA, public personal identity disclosure, publication final approval, tax/payout, ad spend, grant OAuth scopes/connected Meta Pages. No fake followers, comment/DM bots, scrape/reupload or platform session automation.

## Step 1 — PREFLIGHT (no modifications)
Find actual Git branch/repo, verify the two handles' ownership/availability within the authenticated Instagram UI, inspect current Meta/Metricool connections without mutations. Return VERIFIED/UNKNOWN/BLOCKED, never assert that a URL works as an Instagram account.
Check if vectors are usable and export PNG (no image links to an unmerged branch are promised stable).
Do not repurpose the old Metricool free brand.

## Step 2 — PROFILE PACK
Each account: selected display name, bio, master avatar and PNG export, recommended category, privacy visibility matrix, live-proven handle. Preview at 32/48/128 px. Give owner one exact profile approval packet per account.
If owner approves profile-only changes, configure only these explicitly approved fields. Confirm read-back and screenshot, redact tokens/account IDs.

## Step 3 — 14-DAY CONTENT PILOT
Grey: 2 distinct 15–40s Reels per week; original source/proof and visual storytelling, first 1.5s hook, one clear reveal, end on natural payoff. First 4:
1. One million vs one billion seconds — exact calculation, different scaling in time.
2. 23 people / birthday paradox — assumptions visible.
3. 1% independent event repeated 100 times — 1-(0.99^100).
4. Visually fair geometric comparison puzzle with a verifiable answer.
Source QA mandatory, no misleading puzzle ambiguity.

Squirrel: owner sends small, manually approved footage only. Do not invent diaries. Draft:
1. An ordinary real study/work day (15–25s).
2. A carousel with closed-book recall vs re-reading (4–6 panels, evidence-supported).
3. A real moment from work/study/life that prompted a small adjustment (15–30s).
4. A carousel showing a genuine error log/learning technique, with a safe synthetic **example labelled illustrative** if raw screenshot is sensitive.
If owner footage absent, leave diary Reel as CAPTURE_NEEDED; provide shot list and nondeceptive educational alternative.

## Step 4 — MANUAL CAPTURE INPUT
Owner optional capture: 3 tiny 2–5s clips + one sentence about the day, 2 days/week. Avoid all third-party faces, account names, chat text, grades, patient/student/private data, identifiable location and timestamp geotags. Private source inbox chosen by owner, not uploaded to public Git.

## Step 5 — EXPORT AND HUMAN GATE
For each asset produce `content_id, channel, script, factual sources, rights, AI disclosure status, source footage consent, output mp4/png, cover, caption, caption language, safe title, checksum, QA pass/fail, recommended publish window`.
Status sequence: CANDIDATE > SOURCE_APPROVED > DRAFT > QC_PASS > AWAITING_APPROVAL > APPROVED > POSTED > ANALYZED.
Do not schedule/publish merely because post is QC_PASS.
First QA package: 1 Grey Reel + 1 Squirrel carousel (no private life footage needed); then 1 more per account when sources verified. No costly autonomous video-generation farm.

## Step 6 — ANALYTICS (only if post exists)
Record at 24h/72h/7d using official insights or owner export; missing metrics NULL. Age-match, compare separately between accounts and formats. Measure human time so optimization favors sustainable workflow.
No new tool subscription or paid advertising during 14-day pilot. If blocked, report exactly the smallest manual action requested.

## Handoff finish line
1. Two account profile previews and exact approved steps.
2. Four initial QA-ready content packages total, or clearly itemized content waiting on real footage.
3. Live source verification and safe asset download path.
4. Jira and Notion status updated without misrepresenting publish status.
