Create a **separate Grey Visual YouTube channel** managed under owner's existing Google Account / Brand Account if available; **do not** change, transfer, replace, merge, or repurpose existing Many Ways to See or any other YouTube channel. Channel name `Grey Visual`; handle candidate `@greyvisual2026` (UNVERIFIED/NOT RESERVED), alternates `@greyvisual.lab`, `@greyvisualofficial` subject to actual YouTube availability. Do NOT wait for Instagram view success as an eligibility filter for YouTube. Do NOT create separate animation/render projects for each destination. Use separate captions, metadata and optionally frame-safe title variants with the SAME underlying creative truth/provenance.

**This document does NOT authorize any publishing, scheduling, channel creation, paid tools, cross-account profile edits, bulk backfill or rerender.**

## Publishing process by `content_id`

```text
MATHEMATICAL SOURCE + ASSUMPTIONS
             ↓
       REPRODUCIBLE MASTER
        1080×1920 H264
        + provenance SHA256
             ↓
      CREATIVE + RIGHTS QA
             ↓
        OWNER APPROVAL
        /            \
 INSTAGRAM EXPORT   YOUTUBE EXPORT
  platform caption   concise YouTube title
  native cover       description/hashtags
  no other-app mark  same clean source MP4
        \            /
      24h / 72h / 7d observations (each platform separately)
             ↓
     repeat/modify subject-specific ideas
```

- Unique content_id `GV-004` stays the same concept in both platforms. Store `publication_id` `GV-004-IG` and `GV-004-YT` with exact post URL, account/channel ID, final media SHA and timestamp.
- **Do not download the Instagram published copy for YouTube**, and vice versa. Export directly from original code master. Original project assets/provenance and authorship notes are retained so legitimate crossposting cannot be mistaken for scraped/third-party reuse. Avoid platform watermarks and platform-restricted copyrighted music.
- Output media currently planned ~19s for GV-004 / ~23s GV-002, 1080×1920 30fps H264; silent or independently licensed audio after approval, no YouTube copyrighted soundtrack lifted from Instagram.
- Grey YouTube title examples (candidate only):
  - `Same Perimeter. Which Shape Has More Area? #Shorts` (GV-004)
  - `Only 23 People for a Birthday Match? #Shorts` (GV-002)
  - Prefer concise native description and precise mathematical assumption over reusing the full long IG caption word-for-word.
- If the owner creates the channel, start with approved older GV-001 & GV-003 master assets (optional, not mandatory backfill), then approved new GV-004 and GV-002, **never upload without per-platform explicit approval**. Do not upload unfinished preview from PR #5.

## Four-week test and stop/go criteria

Run once new YouTube channel is owner-created and exactly identified; target 4 original Grey ideas on each platform without additional creation:
- Existing two IG posts GV-001 and GV-003 (owner-reported each >120 views, not exact official Insight). Consider one-time clean source uploads to YT only if separately authorized and originals available.
- New GV-004 and GV-002 after their independent media and publishing approvals.
- Each destination needs own 24/72/7-day official analytics; do not compare raw views as same measurement. Since **Aug 24 2026** YouTube public views start at video play; inspect **engaged views, stayed-to-watch, avg viewed %, watch duration, shares, subs** in native YouTube Studio. Instagram separately views, non-follower reach, shares, saves, watch/completion when exposed. Missing values NULL.
- Evidence for Keep: coherent channel positioning, acceptable actual time overhead, more than one video with meaningful watch and repeat/engagement; weak data after 4 items means another modest iteration, not algorithm verdict.
- No paid scheduler/OAuth until manual two-platform publishing per item takes enough measured extra time to justify an official tool. Target incremental operator cost <10 min per mastered video for YouTube metadata/QA (a goal, not measured).
- Review one format difference at a time: e.g. thumbnail title/frame or hook re-edit only after the first 4 content IDs; **'best on IG only' is a rule for optional EXPENSIVE expanded/longform versions**, not for initial YouTube Shorts distribution.

Never claim eligible.

1. Free **Grey Visual Lab** interactive puzzles on existing GitHub Pages, public concept/slider, no immediate SaaS.
2. Original visual explainer modules/diagrams, teacher/puzzle packs or licensing if teachers/audiences ask.
3. Aligned education/tool sponsors after actual reach and explicit paid-partnership disclosures.
4. Some topics could warrant deeper separate Many Ways to See videos, with clear brand attribution and no cheap duplicate as full lesson.

Separate **licensing of our own original code/motion** from platform monetization. Own IP remains an asset even with zero revenue.
